Design Documentation

Google Ads API – Basic Access Application

Tool: Content Dashboard Company: SpeedRopeShop Date: March 2026

1. Overview

Content Dashboard is an internal content planning tool for SpeedRopeShop (speedropeshop.com), an e-commerce store specializing in jump ropes and fitness equipment. The tool helps the site owner decide which blog articles to write for maximum organic traffic and revenue.

The Google Ads API is used exclusively for the Keyword Planner service to retrieve monthly search volumes for target keywords. This data feeds into a scoring model that prioritizes content opportunities.

2. API Usage

2.1 Endpoints Used

customers/{id}:generateKeywordIdeas POST Retrieve average monthly search volumes for target keywords

2.2 Usage Volume

Metric Value

Total keywords per week 10–50
Cache duration 7 days
Users 1 (site owner)

2.3 Data Flow

1 AI generates 10 article ideas with target keywords based on Google Search Console data and autocomplete suggestions
2 Target keywords (10–50) are sent to the Keyword Planner API to fetch monthly search volumes
3 Search volumes are cached in a local database for 7 days to minimize API calls
4 Volumes are used to calculate expected traffic (volume × estimated CTR) and expected revenue (traffic × revenue per visitor)
5 Articles are ranked by a priority score combining search volume, revenue potential, difficulty, and brand fit

3. Architecture

3.1 Technology Stack

  • Framework: Next.js 15 (TypeScript)
  • Database: SQLite (local, single-user)
  • Hosting: Self-hosted VPS
  • Authentication: OAuth2 (web application flow)

3.2 Data Storage

Keyword volumes are cached in a local keyword_volumes SQLite table with a 7-day TTL. Only the keyword text, average monthly searches, and competition level are stored. No personal or advertiser data is collected or shared.

3.3 Security

  • OAuth2 refresh token stored encrypted in a local database (not in code or version control)
  • Dashboard is password-protected and accessible only to the site owner
  • The tool is not publicly accessible or customer-facing
  • No Google Ads data is shared with third parties

4. Compliance

  • The tool accesses only the Keyword Planner service — no campaign management, bidding, or ad creation
  • All API responses are cached to minimize request volume
  • The tool does not modify any Google Ads account data (read-only usage)
  • The tool complies with the Google Ads API Terms of Service
  • The tool is used exclusively for the applicant's own Google Ads account
